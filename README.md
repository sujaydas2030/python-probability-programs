# Python Probability Programs

This repository contains Python programs focused on solving real-world
probability problems using clean logic and mathematical reasoning.

The programs demonstrate:
- Basic probability calculations
- Joint and conditional probability concepts
- Recursive counting of outcomes
- Binomial distribution using factorials

## Files in this Repository

### 1. books_genre_probability.py
Calculates the probability of selecting books from specific genres based on
a predefined genre distribution.

### 2. many_sided_die_probability.py
Computes the probability of achieving a target sum when rolling a many-sided
die multiple times using recursion.

### 3. joint_probability_products.py
Calculates the joint probability of selecting multiple products, assuming
independent events.

### 4. rain_probability_fortnight.py
Uses the binomial distribution formula to estimate the probability of rain
occurring on a specific number of days in a 14-day period.
